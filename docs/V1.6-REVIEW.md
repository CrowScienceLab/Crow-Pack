# CrowPack 1.6.0 검토 보고서

작업 경로: `D:\App coding\Crow-Pack`. 앱/설치본 1.6.0, Store MSIX 1.6.0.0.
검토 후 업로드한다는 요청에 따라 GitHub push, 릴리스, Store 제출은 하지 않는다.

## 드래그 복사 수정

재현: 명시적인 폴더 항목 없이 `project/a/readme.txt`, `project/b/readme.txt`가 있는 ZIP에서
`project/`를 드래그 준비하면 기존 코드는 두 개의 readme.txt URL을 반환했다.
Explorer에 전달되는 순간 상위 구조가 사라지고 동명 파일도 충돌하는 원인이었다.
최소 재현 명령 `python -m unittest tests.test_drag_export -v`의 최초 실행은 실패했다.

- 선택한 디렉터리 루트를 반환하여 명시적/암묵적 폴더의 전체 구조를 보존한다.
- UI의 드래그 선택을 현재 보이는 폴더 기준으로 계산하여 여러 폴더 선택도 유지한다.
- 빈 폴더 선택, 부모/자식 중복 선택, 부분 누락, 같은 이름의 하위 파일을 검사한다.
- 큰 추출은 작업 스레드에서 처리하고 Qt 메인 스레드에서만 네이티브 드래그를 시작한다.
- 버튼을 놓은 경우 성공으로 숨기지 않고 준비 완료/다시 끌기를 안내한다.
- `text/uri-list`의 로컬 폴더 URL과 CopyAction만 전달한다. 원본을 이동/삭제하지 않는다.
- 캐시는 원본 크기/수정시간/선택/비밀번호 지문을 구분하며, 추출 중 앱 종료를 막는다.

## 디자인과 이름

- CrowEyes와 CrowShow의 노란 부리 까마귀 이미지를 참고한 새 까마귀+압축 상자 아이콘.
- PNG: `assets/CrowPack.png`, Windows ICO: `assets/CrowPack.ico`.
- 빌드/앱/파일 연결/Store 로고가 모두 새 자산을 사용한다. 기존 Store Identity와 설치 AppId는
  기존 사용자 업그레이드 호환성을 위해 유지한다. 기존 설치 경로 역시 설치 프로그램이 재사용할 수 있다.
- `Crow_Pack.bat` → `CrowPack.bat`, 표시 이름과 새 설치 기본 경로/바로가기 이름은 CrowPack.
- 누락된 folderUp 벡터와 테이블 셀 배치를 수정하여 undefined/상위 폴더 겹침 제거.
- 홈 벡터에 LED 발광과 글래스 깊이를 추가한다. 모양 자체는 정밀한 Lucide 경로를 유지한다.
- 확장자 순서를 ZIP, 7Z, RAR, TAR.GZ, TAR.XZ, ALZ, EGG, CAB, ISO로 정리한다.
  기존 ALZ/EGG 강조는 한국형 형식 구분 스타일이었으나 우선순위로 오해할 수 있어 제거했다.
  CAB와 ISO에만 보조 색상을 적용한다.

## 자체 점검

- 엔진/보안/배포/드래그 회귀 테스트 60개 통과.
- WebEngine 드래그 payload 및 상위 폴더 실제 DOM 회귀 테스트 통과.
- UI DOM/버튼/네이티브 드롭 스모크 테스트 통과.
- 화면 배치: 100%/150% 각각 126개 조합 검사 통과 (두 언어, 세 테마, 세 크기, 일곱 화면).
- Ruff 정적 검사 통과, pip check 통과.
- 의존성 감사에서 6개 라이브러리의 알려진 취약점 55건 발견 후 수정 버전으로 갱신했다.
  Pillow 13.0.0, pypdf 6.21.2, brotli 1.2.1, certifi 2026.10.23,
  filelock 4.2.4, setuptools 84.2.1. 재감사에서 알려진 취약점 없음.
- Pillow 13의 Python 최소 요구사항에 맞춰 소스 개발 환경은 Python 3.11 이상으로 명시했다.
  Windows 배포본은 기존과 같이 Python 3.12 런타임을 포함한다.

## 검증의 한계 / 사용자 검토

ZIP(암묵/명시 폴더), 7Z(암호 포함), TAR/TAR.GZ/TAR.XZ, ISO의 실제 추출 결과와
네이티브 드래그 MIME 전달을 자동 검사했다. Windows Explorer에 실제 마우스로 놓는 마지막
OS 복사 동작은 이 환경의 화면 제어 제한 때문에 직접 확인하지 못했다. 설치본에서
중첩 폴더/여러 선택/큰 파일을 Explorer로 끌어 실제 복사 완료까지 최종 확인해야 한다.
RAR/ALZ/EGG/CAB 모든 변형을 실제 파일로 검증한 것은 아니다. 기존 포맷별 지원 한계는 유지한다.
