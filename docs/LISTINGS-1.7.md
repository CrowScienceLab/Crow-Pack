# CrowPack 1.7 배포 소개

## GitHub Release · 한국어

### CrowPack 1.7 — Windows용 압축·PDF·ISO 도구

CrowPack은 압축 파일을 탐색·생성하고 PDF 용량을 조절하며 데이터 ISO와 CBZ를 다루는 Windows 10·11용 앱입니다. 파일은 기기에서 처리합니다.

- ZIP·7Z·TAR 계열 압축 생성 및 해제, RAR 열기 및 해제, 데이터 ISO 탐색 및 생성. ALZ·EGG의 일부 해제 기능은 실험적이며, 압축된 RAR은 호환되는 외부 백엔드가 필요합니다.
- 빠른 도구에서 포맷 변환, 여러 압축 파일 일괄 해제, 분할 압축, 이미지 자연 정렬 CBZ 생성, 파일명 암호화를 실행합니다.
- ZIP AES-256으로 내용을 보호하거나 7Z로 압축 파일 내부의 파일명·폴더명까지 암호화합니다.
- 압축 내부의 파일이나 폴더를 선택해 Explorer로 복사하고 이미지를 미리 봅니다.
- PDF를 분석해 권장 프리셋을 확인하고 다섯 단계 중 하나로 사본을 최적화합니다.
- Command Hub 홈, 세 가지 테마, 한국어·English 화면과 진행 안내를 제공합니다.
- 첫 실행 Windows 설정에서 형식별 연결 상태를 확인하고 기본 앱 설정을 바로 열 수 있습니다. 설치 중 기본 선택된 바탕화면 바로가기는 선택 해제할 수 있습니다.
- GitHub 설치본은 새 릴리스가 있을 때 승인 후 파일을 내려받고 SHA-256을 검사합니다. Store판은 Microsoft Store에서 업데이트합니다.

Windows x64 설치 프로그램은 `CrowPack-v1.7-Setup-x64.exe`입니다. 설치 없이 실행하려면 `CrowPack-v1.7-Portable-x64.zip`의 전체 내용을 풀고 `CrowPack.exe`를 여세요. 소스와 SHA-256 목록을 함께 제공합니다. © 2026 Crow Science Lab.

## GitHub Release · English

### CrowPack 1.7 — Archives, PDFs, and ISO images for Windows

CrowPack is a Windows 10 and 11 utility for browsing and creating archives, reducing PDF size, and working with data ISO and CBZ files. File operations run locally.

- Create and extract ZIP, 7Z, and TAR-family archives, browse and extract RAR, and browse or create data ISOs. ALZ and EGG extraction is experimental for some variants. Compressed RAR files require a compatible external backend.
- Use quick tools to convert formats, batch extract, split archives, build naturally sorted CBZ books, and encrypt internal file names.
- Protect contents with ZIP AES-256, or protect internal 7Z file and folder names as well.
- Preview images and copy selected files or folders out of archives into Windows Explorer.
- Analyze a PDF and optimize a separate copy using one of five presets.
- Use the Command Hub, three visual themes, and Korean or English interface and progress messages.
- Review defaults by file type on first launch and open Windows default app settings directly. The installer preselects the desktop shortcut and lets you opt out.
- GitHub installations verify the update installer using SHA-256 after you approve the download. Store installations update through Microsoft Store.

Use `CrowPack-v1.7-Setup-x64.exe` for a Windows x64 installation. For portable use, extract all of `CrowPack-v1.7-Portable-x64.zip` and open `CrowPack.exe`. Source and SHA-256 checksums are included in the release. © 2026 Crow Science Lab.

## Microsoft Store · 한국어 제품 설명

CrowPack으로 압축 파일, PDF, 데이터 ISO와 CBZ를 한 앱에서 관리하세요. ZIP·7Z·TAR 계열 압축 파일을 만들고 풀거나 RAR의 내용을 확인할 수 있습니다. 홈의 빠른 도구에서 포맷 변환, 일괄 해제, 분할 압축과 이미지 자연 정렬 CBZ 만들기를 실행하세요.

공유할 자료는 ZIP AES-256으로 보호하거나 7Z 내부 파일명과 폴더명까지 암호화할 수 있습니다. 데이터 ISO를 열어 파일을 복사하거나 새 이미지를 만들고, PDF 분석 결과에서 권장 단계를 확인한 뒤 다섯 프리셋 중 하나로 저장 용량을 줄이세요.

Windows 설정 화면에서 파일 형식별 기본 앱을 확인하고 변경 화면을 바로 열 수 있습니다. 바탕화면 바로가기는 첫 실행이나 앱 설정에서 원할 때 만들 수 있습니다. 한국어와 English, 세 가지 화면 테마를 지원하며 파일 처리는 기기에서 이뤄집니다.

- 데이터 ISO 탐색·복사·생성, 5단계 PDF 용량 조절

- 한국어·English와 세 가지 화면 테마, 기기 내 파일 처리

### Microsoft Store · 한국어 이번 버전의 새로운 기능

Command Hub에서 기존 압축·PDF·ISO·CBZ 도구를 빠르게 열 수 있습니다. 1.7은 파일 형식별 기본 앱 안내와 바탕화면 바로가기 만들기를 추가하고, 진행 안내와 PDF 분석의 한영 표시, 압축 해제 검증과 Store 업데이트 동선을 개선했습니다.

## Microsoft Store · English product description

Manage archives, PDFs, data ISO images, and CBZ books with CrowPack. Create or extract ZIP, 7Z, and TAR-family archives, or browse the contents of a RAR file. Use the quick tools to convert formats, extract several archives, split a large archive, or build a naturally sorted CBZ book from images.

Protect files with ZIP AES-256 or encrypt internal file and folder names in 7Z. Browse and copy files from data ISO images or create a new one. Analyze a PDF to see the recommended preset, then choose one of five options to produce a smaller copy.

Review defaults by file type and open Windows default app settings directly. Create a desktop shortcut from first launch or from Settings when you want one. CrowPack offers Korean and English, three themes, and local file processing.

### Microsoft Store · English app features

- Browse, copy, and create data ISO images. Optimize PDFs with five presets.
- Per-type defaults, a direct link to Windows settings, and optional desktop shortcut creation.
- Korean and English, three visual themes, and on-device file processing.
