# Crow Pack 1.5.3 검토

작업 경로: `D:\App coding\Crow-Pack`

## 디자인

도구모음·탐색기·홈·다섯 도구의 벡터 아이콘 23개를 Lucide 0.468.0으로 교체했다.
24×24 좌표계, 둥근 선 끝, 동일 선 두께를 사용한다. 라이선스는
`assets/LUCIDE-LICENSE.txt`에 포함했다. 기존 Crow Pack 브랜드 로고는 유지했다.
홈 도구모음에 기능명을 표시하고 도구 탭은 아이콘 영역과 명칭 영역을 분리했다.
설정은 아이콘 없이 기존 섹션 구조를 유지하고 설명 글자의 가독성을 높였다.

“개인정보 보호”는 “파일명까지 암호화”로 변경했다. ZIP은 내용만 암호화하고
7Z는 내용과 내부 목록을 암호화한다는 차이를 옵션 안내에 표시한다.

## .7z 연결 조사

검사에서 `CrowPack.7Z\shell\open\command`가 다음 경로를 가리켰다.

`C:\Users\user\Documents\ChatGPT\Crow App Build\Crow-Pack\dist\CrowPack\CrowPack.exe`

해당 실행 파일은 존재하지 않았다. 삭제된 개발용 실행 파일을 연결 대상으로
사용한 등록이 남은 것이 확인됐다. Windows의 실제 사용자 선택(UserChoice)과
Store 설치 상태는 검사 계정과 사용자 세션이 다를 수 있어 최종 원인 확정에는
새 설치본으로 사용자 세션에서 더블클릭 검증이 필요하다.

- 일반 설치본: 설치 후 안정적인 설치 경로를 등록한다. 앱에서 연결 설정을
  열 때도 현재 실행 경로를 다시 등록하여 남은 경로를 복구한다.
- Store: 등록 이름 대신 패키지 AUMID를 사용해 기본 앱 설정으로 이동한다.
- Store manifest: 인수 `"%1"`을 명시하여 공백 포함 파일 경로를 전달한다.
- 연결 상태는 다른 앱이 지정된 형식을 Crow Pack 연결로 집계하지 않는다.
- Windows의 보호된 UserChoice나 기본 앱 선택은 강제로 변경하지 않았다.

참조: https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings
및 https://learn.microsoft.com/en-us/uwp/schemas/appxpackage/uapmanifestschema/element-uap3-filetypeassociation

## 기능·보안

- 압축 항목의 Windows 대체 데이터 스트림(콜론), 금지문자, 제어문자를 차단했다.
- 7Z는 해제 전에 각 대상 경로를 확인하여 기존 링크·정션을 통한 폴더 외부
  경로로의 해제를 차단한다.
- 7Z 해제 결과에 대상 폴더의 기존 무관한 파일이 포함되던 문제를 수정했다.
- EXE의 표시 버전과 숫자 버전이 다르던 문제를 수정했다.
- pypdf 6.18.1과 개발 도구 의존성 urllib3 2.7.0의 알려진 취약점 6건을
  pypdf 6.19.0 / urllib3 2.8.0으로 갱신하여 해결했다.

## 검증

- 엔진·암호화·보안·배포 회귀 테스트 54개 통과.
- Ruff 정적 검사 통과.
- pip-audit: 알려진 의존성 취약점 없음. 자체 프로젝트는 PyPI에 없으므로
  의존성 감사 대상에서 제외되며 위 소스 검사와 테스트로 검증했다.
- 실제 Qt WebEngine 배치 검사: 100%와 150%에서 각각 126개 케이스 통과.
  최소 680×460, 기본 780×520, 960×620, 두 언어, 세 테마, 홈·설정·다섯 도구.
- UI DOM/버튼 동작·드롭 스모크 테스트 통과.

새 버전은 앱·GitHub 배포 파일 `1.5.3`, Store MSIX `1.5.3.0`이다.
설정 창의 섹션 간격과 상하 여백만 추가 조정했다. 내용이 실제로 넘치는 작은 창에서는
스크롤을 유지하며 기본 크기에서는 불필요한 세로 스크롤이 생기지 않도록 검사한다.
