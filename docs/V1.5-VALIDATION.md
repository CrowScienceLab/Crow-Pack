# Crow Pack 1.5.0 검증 및 Windows 통합

## 구현

기존 ArchiveManager와 포맷 처리기를 재사용한다. 개인정보 보호 모드는
7Z AES 암호화 필터와 헤더 암호화를 함께 사용한다. ZIP AES는 이름을 숨기지 않는다.
비밀번호는 메모리와 사용자가 요청한 클립보드 복사에만 사용하며 설정·로그에 저장하지 않는다.
암호 강도 표시는 길이 기반 안내이며 보안 강도를 보장하는 측정치는 아니다.

CBZ는 ZIP 기반 이미지 문서다. 자연 정렬 및 선택적 001.png 페이지 이름을 제공한다.
변환은 전용 임시 폴더에서 안전하게 해제하고 재압축한 뒤 무결성 및 재해제 검사 후
새 파일로 저장한다. 원본과 기존 출력은 덮어쓰지 않는다.
SHA-256은 1 MiB 단위로 처리한다. SHA256SUMS에는 출력 파일 기준 상대 경로를 사용한다.
Batch는 실패한 파일을 기록하고 나머지를 계속 처리하며 같은 이름의 별도 폴더는 번호를 붙인다.

## Explorer 드래그

파일 행을 왼쪽 버튼으로 끌면 기존 안전한 추출 경로로 선택 항목을 준비한 후
QDrag/QMimeData 로컬 URL 복사를 시작한다. 큰 파일 준비 도중 버튼을 놓은 경우
다시 끌도록 안내하며 준비된 파일을 재사용한다. Ctrl/Shift와 기존 체크박스 선택을 유지한다.
`%TEMP%\CrowPack\drag\<UUID>`에만 파일을 만든다. 최근 파일은 앱 종료 후에도
Explorer 복사 완료를 위해 유지하고, 7일 이상 지난 전용 UUID 세션만 정리한다.
이 임시파일은 일반 로컬 파일이므로 개인정보 추출 후 공유 PC에서는 로그아웃 전에
해당 세션 작업을 마치고 시스템 임시파일 정리 정책을 적용할 수 있다.

## Windows 메뉴와 연결

HKCU ProgID, Capabilities, RegisteredApplications, OpenWithProgids를 등록한다.
UserChoice는 읽기만 하며 쓰기·해시 변경·UCPD 우회를 하지 않는다.
Office 문서와 APK/JAR는 기본 연결 대상으로 등록하지 않는다.
기존 기본 앱이 없는 확장자만 legacy fallback을 설정한다.
현재 연결 표시는 Windows AssocQueryStringW로 조회한다.

설치본은 등록을 실행하고 마지막 페이지에서 Windows 기본 앱 설정을 열 수 있다.
제거 시 Crow Pack 소유 키·값을 정리하며 다른 프로그램 키를 삭제하지 않는다.
Windows 10은 공식 기본 앱 페이지로 이동하고, 지원되는 Windows 11에서는
`ms-settings:defaultapps?registeredAppUser=Crow%20Pack`을 사용한다.

클래식 메뉴는 Windows 11의 '더 많은 옵션 표시'에서 사용할 수 있다.
Document 메뉴의 파일별 실행은 사용자 전용 QLocalServer로 모아서 하나의 창에 전달한다.
대규모 선택에서는 Windows의 classic verb 선택 수 제한이 적용될 수 있으므로 앱의
다중 파일 선택 또는 드롭을 사용한다. 작업은 앱에서 결과와 저장 위치를 확인하며 실행한다.

Windows 11 현대식 메뉴 직접 노출은 IExplorerCommand와 앱 식별자를 갖춘 패키지
등록이 추가로 필요하다. Inno Setup 배포에서는 클래식 메뉴를 제공한다.

공식 참고:
- https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer
- https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings
- https://learn.microsoft.com/en-us/windows/win32/api/shlwapi/nf-shlwapi-assocquerystringw

학교/기관 관리 PC에서는 Windows Default App Associations 정책으로 관리자 배포가
가능하다. 앱 자체는 관리 정책이나 기존 사용자 기본 앱을 강제 변경하지 않는다.

## 디자인

CrowLink Generate-Icon.ps1의 #080C12, #EDF8FF, #59D8EC와 굵은 실루엣을 참고했다.
Crow-Pack은 대칭형 까마귀와 청록 패키지를 결합한 고해상도 RGBA PNG 원본과
16/24/32/48/64/128/256 ICO 및 ZIP/7Z/RAR/TAR/ISO/CBZ 배지를 생성한다.
툴바는 24px viewBox, 1.8px 둥근 선, currentColor 방식으로 테마에 대응한다.

## 검증 범위

자동 검사는 기존 기능, 7Z 헤더/데이터 암호화, 잘못된 비밀번호,
CBZ 자연 정렬/선택 해제, 변환과 원본 보존, streaming checksum,
batch 혼합·실패·충돌, ZIP/7Z/TAR/ISO drag 준비와 traversal 차단을 포함한다.
### 2026-09-09 로컬 패키징 결과

- Python 단위 테스트 44개 통과, Ruff 검사 통과.
- 기본 창을 58px 아이콘 툴바와 고정 홈 작업 영역으로 재구성해 불필요한 세로
  스크롤을 제거했다. 도구는 포맷 변환·일괄 해제·CBZ·개인정보 보호·분할 압축의
  다섯 기능을 한 줄에 노출하고, 설정은 아이콘 없는 세 구역 목록으로 단순화했다.
- 실제 Qt WebEngine에서 680×520, 780×520, 960×620, 한국어/영어, 3개 테마,
  배율 100/125/150/200%의 216개 화면 조합에 대해 경계·잘림·스크롤 검사를 통과했다.
- 배포 실행 파일과 격리 설치 실행 파일 모두 버전 1.5.0, UI/브리지 초기화
  smoke test를 통과했다. 제한 계정에서는 설치 폴더 상수 조회 및 WebEngine
  로딩이 실패했으나 일반 사용자 환경에서 설치 종료 코드 0과 UI 초기화를 확인했다.
- 격리 설치는 같은 파일 payload를 사용하되 등록/바로가기/제거 등록을 끈
  ValidationBuild로 수행했다. 기존 설치 앱과 기본 파일 연결은 변경하지 않았다.
- 패키지 앱에서 한글 이름 파일이 포함된 ZIP 열기를 확인했다.
- Explorer로의 실제 드롭 복사 및 해시 일치 검증은 미완료다. 드래그 준비
  엔진 검사는 통과했지만 이를 Explorer 통합 검증 완료로 간주하지 않는다.
- 실제 기본 앱 변경, 설치 업그레이드/제거 시 연결 복원, 전체 우클릭 메뉴,
  RAR/ALZ/EGG 실물 파일의 전체 회귀 검증은 추가 수동 확인이 필요하다.
- 설치본/포터블/소스와 SHA256SUMS는 로컬 검토용이며 GitHub에 업로드하지 않았다.
- 앱 아이콘은 이미지 생성 도구로 만든 대칭형 까마귀/압축 박스 RGBA 원본을 사용했고,
  이를 16/24/32/48/64/128/256 크기의 Windows ICO로 변환해 적용했다.

클린 Windows 10/11 각각의 VM, 한글 사용자 계정, 모든 DPI 조합은
현재 호스트의 자동 검사만으로 검증 완료로 간주하지 않는다.
