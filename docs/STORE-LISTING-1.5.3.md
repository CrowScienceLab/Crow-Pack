# CrowPack 1.5.3 배포 소개

## 한국어

압축 관리에 PDF 용량 조절, CBZ 만들기, ISO 읽기/쓰기, 파일명까지 암호화를 더했습니다.

CrowPack은 Windows용 로컬 파일 도구입니다. ZIP·7Z·TAR 압축과 해제뿐 아니라,
PDF 최적화, 이미지 문서 만들기, 데이터 ISO 탐색과 생성까지 한 앱에서 처리합니다.

- PDF 용량 조절: 무손실 정리부터 이미지 재압축까지 다섯 단계로 선택합니다.
- CBZ 만들기: 이미지 파일을 자연 정렬해 만화·그림 문서로 묶고 미리 봅니다.
- ISO 읽기/쓰기: 데이터 ISO의 파일을 열고 복사하거나 새 ISO 이미지를 만듭니다.
- 파일명까지 암호화: 7Z의 내용과 내부 파일명·폴더명을 비밀번호로 보호합니다.
- 다섯 도구: 포맷 변환, 일괄 해제, CBZ 만들기, 파일명까지 암호화, 분할 압축.
- 한국어/English와 세 가지 화면 테마를 지원합니다.
- 사용자 파일을 서버에 올리지 않고 작업을 로컬에서 처리합니다.

ZIP 암호화는 내용만 보호합니다. 외부 압축 파일 이름은 숨겨지지 않습니다.
ISO 쓰기는 데이터 이미지 생성이며 디스크 굽기나 부팅 ISO 제작은 지원하지 않습니다.
PDF의 극한 압축은 페이지를 이미지로 바꾸므로 텍스트 선택·링크 등이 사라질 수 있습니다.

1.5.3: 도구 아이콘과 설명 개선, 파일명 암호화 명칭 정리, 설정의 불필요한 스크롤 수정,
Windows 파일 연결과 압축 해제 보안 개선.

## English

More than archives: PDF size optimization, CBZ creation, ISO reading and writing, and encrypted file names.

CrowPack is a local Windows file utility. Create and extract ZIP, 7Z and TAR archives,
optimize PDFs, organize images into CBZ books, and explore or create data ISO images in one app.

- PDF size optimization: five presets, from lossless cleanup to image recompression.
- CBZ creation: naturally sort images into comic or picture books and preview them.
- ISO reading and writing: browse and copy files from data ISOs or create new ISO images.
- Encrypt file names: protect 7Z contents and internal file and folder names with a password.
- Five visible tools: conversion, batch extraction, CBZ creation, file-name encryption, and split archives.
- Korean and English, with three visual themes.
- File operations run locally without uploading your files to a server.

ZIP encryption protects contents only. The outer archive name remains visible.
ISO writing means data-image creation, not disc burning or bootable ISO authoring.
Extreme PDF compression rasterizes pages and may remove selectable text, links and other document features.

1.5.3 improves tool icons and descriptions, clarifies file-name encryption, removes unnecessary
settings scrolling, and improves Windows file associations and extraction safety.
