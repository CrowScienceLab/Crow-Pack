• 압축 해제: 압축 파일을 열면 상단 도구로 현재 폴더 또는 지정 폴더에 풀 수 있습니다.

• PDF 용량 조절: 문서 구성을 먼저 분석하고 다섯 가지 단계 중 하나를 선택하면 세부 설정은 자동 적용됩니다.
